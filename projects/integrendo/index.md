# A New INTEGRative Taxonomy of the Molecular Causes of Endometrial Infertility Based on a Multi-Omics Approach Aimed at Precision Medicine (INTEGRENDO)

![Descripción de la imagen]({{ '/images/projects/integrendo.png' | relative_url }})

Since 2026, this project has been funded with €199,771 by the State Research Agency (AEI) as part of the Research Consolidation Incentive Program. 

The main objective of this project is to conduct an in-depth analysis of the multiple causes of endometrial implantation failure as a whole, using a multi-omic approach. 

This will lay the groundwork for developing a preventive diagnostic tool using artificial intelligence methods, as well as for advancing personalized medicine capable of improving reproductive outcomes.
